# Expense Splitter
Project Tasks
1. Menu System (main.py): Build a menu loop with options:
- Add Expense
- View All Expenses
- View Split Summary
- Exit
2. Add Expense (tracker.py): Prompt for payer name, expense description, and amount. Append the information to
parallel lists in `data.py`
3. View All Expenses: Print each payer, description, and amount in a formatted list
4. Split Summary: Ask for the number of people sharing the expenses. Show total expenses, number of expenses,
average expense, highest expense, lowest expense, and equal share per person
